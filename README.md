# Household Expense Tracker API

RESTful API for managing household income and expenses.

## Tech Stack

- C#
- ASP.NET Core
- Entity Framework Core
- SQL Server
- JWT Authentication
- RESTful API
- Swagger / OpenAPI

## Features

- JWT Authentication
- Role-based access
- Database-driven permissions
- Income management
- Expense management
- Expense categories and subcategories
- Expense items
- Lookup APIs
- Audit tracking
